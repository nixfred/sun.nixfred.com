## Build discipline

Do not create empty placeholder pages.

Do not create links marked coming soon.

Do not use lorem ipsum.

Do not create fake payment fields.

Do not weaken copy for fear that users will mistake it for a real nonprofit. The single final disclaimer and the technical inability to collect money are the boundaries.

## Suggested content architecture

Use structured data files where possible:

content/programs

content/blog

content/press

content/reports

content/leadership

content/partners

content/policies

This allows the site to become large without duplicating layout code.

## Suggested project memory summary

Save the Sun is a static institutional parody website. It must appear fully functional but must never collect payment details, transmit forms, create accounts, or accept money. All interactions are local simulations. The site stays completely serious until one concise disclaimer at the absolute bottom.
