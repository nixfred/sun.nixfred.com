   with fine hairlines. Vanity Fair covers a crisis. Implementation:
   Playfair Display for headlines (OFL licensed, self hosted via
   fontsource, no CDN). Neutral modern sans for body and controls:
   Public Sans. Mono for data and metadata: IBM Plex Mono.
2. Sun imagery: NASA SDO public domain solar photography. Credited in
   character, imagery reviewed by the Solar Wellness Monitoring team. AI
   generation reserved for people and editorial scenes.
3. Logo and identity assets: BOTH tracks. Larry builds the code first SVG
   seal suite (crisp, derivable favicon and certificates). AND Larry

   assets: report covers, editorial imagery, headshots, hero scenes. See
   docs/assets/MIDJOURNEY_PROMPTS.md.
4. Motion: FULL institutional motion. Live countdown, metric count ups,
   status pulse, scroll triggered chart reveals. Everything honors
   prefers-reduced-motion.

saving the Sun. The more the better, but no repeats. Standing quality goal:
every surface of the site believes. Metrics believe. Fine print believes.

404 believes. No surface is neutral, and no two surfaces make the same
